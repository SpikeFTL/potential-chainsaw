# SQLMind Demo Script

1. Start the backend on port 8001.
2. Start the React frontend.
3. Show the Backend Online status.
4. Click View Schema and explain the five demo tables.
5. Ask: Show average score by course.
6. Point out the generated SQL and result table.
7. Switch to Smart Analysis and ask: Analyze student performance.
8. Switch to Dashboard and ask: Create a student performance dashboard.
9. Demonstrate safety using the SQL endpoint with DROP TABLE students; it must be rejected.
10. Explain that DEMO_MODE can be disabled and NVIDIA_API_KEY supplied for live LLM-generated SQL.
